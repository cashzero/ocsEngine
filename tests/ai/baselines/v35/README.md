# Frozen heuristic@35 regression opponent

These policy, analysis, decision, and weight files preserve the standard strategy that the next promotion must beat. `manifest.json` records the original v35 source hashes and the hashes after relocating imports. Knowledge, odds, and public model types are shared through small re-exports because their behavior has not changed since v35. The opponent uses the candidate's rule-action facade and reducer, just as the paired match harness does.

Do not update these files when changing the candidate. Changing both policies in a historical continuation can strengthen the opponent and change the winning side; it does not isolate the candidate's VP improvement. The replacement test separately checks complete same-policy operation and the original minimum 2 VP against this fixed opponent. Independent paired matches remain the authority for promotion.
