# R0 Ground / Logistics MVP Scope

## Observable completion

The fixed synthetic scenario can run headlessly through Movement, Supply, Reaction, Combat, Exploitation, Clean Up, and turn end. Public actions drive every mutation. Queries provide legality, candidates, facts, reasons, dependencies, citations, and viewer-safe projection. Transactions persist supply choices and RNG commit boundaries. Replay produces the same final state and events.

The covered ground slice includes exact movement cost, voluntary mode changes, stacking, purpose-specific ZOC, trace/dump supply, combat supply reservation, regular combat, overrun, artillery barrage, step loss, retreat, advance, reinforcement, cleanup, objective control, and turn-limit victory.

## Non-goals

This milestone does not implement Gameplay session/history ownership, UI state, random generation, AI policy, networking, or commercial scenario extraction. Air, naval, detailed rail/shipping, extenders, breakout/attrition tables, capture/blowing-dump tables, replacements, engineering, and optional rules remain manifest-deferred and fail fast.

The Rule Engine consumes Foundation types and the synthetic fixture. It does not modify Foundation ownership or import Gameplay/UI/generation/AI packages.
