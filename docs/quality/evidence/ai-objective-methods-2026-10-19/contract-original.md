Caller:
python3 scripts/ai-objective-study.py --manifest <position recorder manifest> --artifact-root <repo containing raw rows> --engine <compiled engine directory> --out <artifact directory>

Python reuses ai-position-validate.load_games for verified input identity and aliases, writes worklist.json, invokes node scripts/ai-objective-replay.mjs --input <worklist> --engine <engine> --out <observations.json>, then scores and writes analysis.json and predictions.jsonl. JS replay owns observation windows and target labels. Python owns statistical transformation and models. No rule/policy changes.

Worklist schemaVersion1: artifactRoot absolute; games array {id,mapSeed,aliases,expectedWindows}. aliases are existing validator aliases with source/file/match/saveSha256/acceptedActionsSha256/initialStateHash/finalStateHash. Each expectedWindow {id,gameTurn,playerTurnIndex,phasingPlayerId,role,expectedTurn}; id is gameID:gameTurn:playerTurnIndex. expectedTurn equals the original recorder before.turn object for both players. Exactly its existing156 windows from12trajectories8seeds for this cohort; generic CLI computes rather than hardcodes these counts.

Observations schemaVersion1: provenance {inputSha256,engineSha256,extractorSha256}; games array {id,mapSeed,aliases,replay,windows}. Each window {id,gameTurn,playerTurnIndex,role,phasingPlayerId,otherPlayerId,startRevision,endRevision,startStateHash,endStateHash,targets,declarations,reconciliation}. Every configured objective is a target, including already-held and neutral targets for accounting.

Each target {hexId,points,initialHolder,endHolder,features,conditions,controlEvents,labels}. labels {everCaptured,retainedCapture}, retainedCapture=endHolder===P, everCaptured is actual holder transition intoP in this window. controlEvents {actionIndex,revision,from,to,actionKind}. Snapshot features are computed before any action in its window, fixed through all later actions. No future declarations/outcomes allowed in features. Primary statistical rows are initialHolder===O only. Neutral and initiallyP-held rows are audit data; no claim of full netVP prediction.

features exact keys: occupied (enemy combat unit on target 0/1), nearestP (min distance capped10 over all own on-map combat units), ownAbsent (0/1), nearestO (min distance capped10 over all opposing on-map combat units), opponentAbsent (0/1), points, turnFraction (gameTurn/turnLimit), attackerMoving, defenderMoving; logRatio (log1p own eligible printed strength within2 / max(1, enemy printed strength within2)), zeroEnemyStrength; column (conditional supplied-defender columnIndex/12), supplyColumnGain ((unsupplied-supplied columnIndex)/12), drm, hedgehog; noAdjacent, undefended, lineClose, lineVeryClose, lineExtremelyClose. Conditional numeric features column/supplyColumnGain/drm/hedgehog are null when not computed; other keys numeric finite. Ratio own cohort excludes HQ, STRAT and marked OOS; enemy cohort includes all combat units. Keep detailed member IDs, current face/steps and printed contributions in conditions.

conditions.combat discriminated kind: undefended when no enemy combat defenders on this target; noAdjacentFormation if defended but no actual adjacent eligible own combat units (exclude HQ/STRAT, allow DG/OOS as conditional rules handle modifiers); computed otherwise. No relocation, mode flip, fuel assumption or payable-plan claim. Computed result calls engine calculateCombatOdds on same real adjacent formation twice, all defenderIds supplied vs none. Attacker and defender leaders are deterministic maximum combatActionRating among their members, tie by ID. Explicitly pass leader IDs. Legitimate AR0 is allowed; null/missing leader when computed is an error. Retain stacks, modified defenders, terrain line, strengths, column, DRM, hedgehog, leader IDs/AR and source contributions. Assert all current CRT lines have13columns; model line indicators cover OPEN/CLOSE/VERY_CLOSE/EXTREMELY_CLOSE. No Surprise probabilities claimed.

Replay: verify source/save/acceptedActions/initial/final hashes and trace accepted action/revision/step keys. Reproduce original first-action turn boundaries and only eligible expectedWindows. Freeze snapshots, hash state before and after snapshot/diagnostic queries. Run observer-disabled control applyAction in parallel to observed replay after each action, compare state hash, events hash and acceptance; all16aliases exact identity allows replay12unique only. Gather actual DECLARE_COMBAT explain/forecast witnesses for matching targets in declarations, kept outside features. Preserve all per-action target-holder changes, check per-player gross objective count/VP gains/losses against expectedTurn and signed VP delta against all-target endpoints. Label retained vs ever and recaptures separately. Engine errors, missing windows, unresolved identities or accounting mismatches abort.

Models fixed before new extraction/results:
M0 prevalence=(training positives+.5)/(training target rows+1).
M1 ridge logistic baseline keys occupied,nearestP,ownAbsent,nearestO,opponentAbsent,points,turnFraction,attackerMoving,defenderMoving.
M2 M1 plus logRatio,zeroEnemyStrength.
M3 M2 plus column,supplyColumnGain,drm,hedgehog,noAdjacent,undefended,lineClose,lineVeryClose,lineExtremelyClose.
All models use same complete primary rows. Train-only medians for null numeric columns; if no computed training values, use0. Train-only means/scales, zero variance maps0. Exact objective is SUM binary cross-entropy +0.5*sum(standardized slope coefficients squared); lambda1, intercept unpenalized. This keeps the fixed sum-loss convention of existing small-model comparisons; do not silently use mean-loss lambda1. Newton/IRLS with line search, max100 iterations, explicit convergence; nonconvergence aborts. One-class training falls back to M0 and is flagged. No tuning, selection, class weights or fitted post-calibration.

Eight leave-one-map-seed-out folds in this cohort, pooled-role fits with role indicators. Subset scores use the SAME outer-fold predictions, not within-role refits. All aliases/seats/targets/turns of a seed remain together. Primary single contrast M3 versus M1; M0/M2 and all role/fold results reported descriptively. Primary score Brier, secondary log loss clipped for scoring only at1e-6. Fixed reliability bins [0,.05,.1,.2,.4,.6,.8,1]. Always output count, event rate, mean predicted probability, error and bin occupancy; Brier alone is not calibration. Target expectedVP=points*p.
