# Cross-seed stability of candidate measurements

This is descriptive post-result meta-analysis of the existing40pair panel,
not a new predictor search or independent confirmation. The premise under test
is that an early mechanism diagnostic reflects a policy behavior difference
that persists across the other seeds. Include all12 registered diagnostics,
the rejected combined combat window, historical VP/M0/M1/M2, and finalVP itself
as an outcome reproducibility control. No candidate or zero feature is omitted.

Use the same four oriented dev/eval partitions already frozen. For each variable
and partition report Spearman correlation across the10 variants between its
DEV-seedmean and EVAL-seedmean. Average tied ranks, constantvector->null. Also
report per-family double-minus-half contrasts in each seed half, their rank
correlation across five families and same-sign/nonzero counts. Keep underlying
values and all four splits. Bothzero/ties are distinct from informative agreement.
These four overlapping splits do not create new independent observations; do not
infer a confidence interval, population reliability coefficient, noise ceiling,
power or p-value from them. The scale/family selection and four seeds constrain
interpretation. Raw finalVP consistency directly checks target repeatability here,
not an upper bound for a better predictor. Use the existing tested ranks/pearson
helpers. No policy reward, causal effect or qualification follows.

If target or candidate contrasts reverse between halves, test more seed support
or a genuinely different behavioral measure before adding another fitted gate
count. Preserve all results even if stability contradicts prior impressions.
