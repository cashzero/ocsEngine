### 13.3h「明確在敵方前線後方」的判定（RC2 設計）

規則只說「明確」（clearly），沒有演算法。本專案的定義，在每次 phase 或 segment 改變時判定：

- 一方的「可及區」：從己方地圖邊緣補給來源與己方地圖上的戰鬥單位出發，往相鄰格擴散；
  不能進入有敵方戰鬥單位的格；進入敵方 ZOC 格（沒有己方戰鬥單位 negate）可以，但不能再往外擴散。
- 車站只有一方可及、另一方不可及時，控制歸可及的一方；雙方都可及或都不可及時視為「有疑義」，控制不變。
- 只套用到車站格（13.3h 只關心可下車格）。同時也是目標的車站不套用，目標 VP 的控制仍只在戰鬥單位進入時改變。

這個定義讓攻方的鐵路終點只會推進到前線已經「包過去」的車站；敵方 ZOC 線前方、仍在爭奪中的車站維持原控制。

## 5. 實作與量測紀錄

### 規則（RC1、RC2）

- 動作 `RAIL_MOVE { fromHexId, toHexId, unitIds, supply }`；引擎依序找「全程多軌且不經 Trainbusting zone」（成本減半）、
  「不經 zone」或「全程多軌」（原價）、「任何路徑」（加倍）中第一個存在的路徑。路徑只走「貨運鐵路網」：從己方地圖邊緣的
  鐵路補給來源出發，不進入敵方戰鬥單位、敵方 ZOC（不可 negate）、非己方控制的車站。
- 上下車格：車站（村莊、城鎮、城市）或 Combat Mode 的 Engineer-Capable HQ 所在鐵路格，己方控制、在貨運鐵路網內、沒有敵方單位、不在敵方 ZOC。
- 單位：戰鬥單位須在 Move Mode，運輸點（不含 Extender）不限模式；上車前已用的 MP ≤ 一半 MA；下車後 MA 用完、標記 `railCarried`，
  同一 phase 不能再移動或搭飛機（14.9 也檢查）。成本：RE（Leg、Move Mode MA 1–6 減半）、卡車按點數、SP 每 1T 為 1/4 點；以 1/4 點計，減半無條件進位。
- SP：從上車格的己方地面補給堆取，扣掉本 phase 卸下的量（12.2a）；下車後合併到目的地補給堆，並記為本 phase 卸下（不能再裝卡車）。
- 13.6b：Reinforcement Phase 放在鐵路進場格的增援與新 SP 記在 `GameState.rail.arrivals`（本 Game Turn 有效）；即使進場格不是車站，也可在那裡上車，數量以到達量為上限。
- Rail Cap 帳 `GameState.rail.spent` 以（Game Turn、player turn）為鍵，換 phase 不帶過去（13.3b）。舊存檔沒有 `rail` 欄位，雜湊不變。
- 13.3h 前線控制：每次 phase 或 segment 結束時，從雙方地圖邊緣補給來源與地圖上的戰鬥單位往外擴散（不進敵方戰鬥單位、不從未被 negate 的敵方 ZOC 繼續擴散）；
  只有一方到得了的車站改歸該方，雙方都到得了或都到不了視為有疑義、不變。目標格不套用；沒有 Rail Cap 的舊遊戲不套用。
- 規則清單：`movement.rail-cap`、`supply.rail-front-control`（PARTIAL，GAP 寫在 `src/rules/manifest.ts`）；`movement.sea` 仍 deferred。

### New Game 與 UI（RC3、RC4）

- `NewGameRequest.railCap?: { allied, axis }`（0–30 整數）；缺省用 `defaultRailCap`：每方 `round(師數 × 0.75)`，至少 1（2026-10-12 由 0.4 調高）（攻方用 1.5 倍後的師數）。
- 表單「Game rules」有 Allied／Axis Rail Cap 兩欄；玩家改過後保留其數值，旁邊可按「Use the default」。預覽 metrics 顯示「Rail Cap: Allied x · Axis y」。
- 遊戲中：選到站在可上車格的己方單位或補給堆，Unit 分頁出現「Rail from 〈格〉」：剩餘 Rail Cap、該格每個單位（不能搭的會灰掉並寫原因）、
  補給堆可輸入 Token 數、可下車車站在地圖上高亮並列在下拉選單（含距離、減半／加倍）；成本與阻擋原因由規則引擎算。

| 空卡車總是開往「全圖最大的補給堆」，也就是新補給到達的地圖邊緣，繞過鐵路終點 | 取貨點選「到取貨點再到主攻」路程最短的後方補給堆，同時算可運量；鐵路送到鐵路終點後由卡車接駁 |

| 載貨卡車停在主攻單位後方好幾回合不卸貨（主攻單位貼著敵人，卡車不敢靠近；所在格又沒有己方單位或補給堆，13.2f 不能卸） | 卸貨點改為離主攻最近、離敵 ≥ 3 格、有己方戰鬥單位或補給堆的格子；到不了時就在主攻 6 格內能卸的地方卸下 |
| 空卡車去拿救援被切斷部隊的補給，或駐守單位腳下的 2T | 只從離敵 ≥ 5 格的後方補給堆取貨，不碰駐守單位補給；鐵路也不運駐守單位補給或目標格上的補給 |
| 卡車 45 MP 可到的格子超過候選上限（400），遠程路線被截掉 | 卡車移動候選上限 3,000 |
