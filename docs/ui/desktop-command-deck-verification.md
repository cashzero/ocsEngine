# Desktop command deck 驗證紀錄

日期：2026-09-06。此紀錄是本次桌面 UI 改版的限定範圍驗證，不代表完整產品驗收。

整體 UI／New Game gate 狀態：`IN PROGRESS`。驗收權威為 `docs/quality/03-product-operation-verification-plan.md`；下列局部測試不得推論為其他操作已通過，未在指定邊界驗證的操作維持 `UNVERIFIED`。

## 已實作

- 單一 380px 左側指令欄，移除右側操作欄；沿用既有 unit counter renderer。
- 階段、選取單位、行動選擇、結果摘要與確認操作固定；Units、Stack、HQ、Choices、History 使用局部清單捲動。
- 地圖呈現可選目的地與移動路徑；移動費用與剩餘額度取自規則查詢。
- 候選行動先依選取單位過濾，再套用數量限制，並提供載入更多。
- Session 與規則細節改為對話框；New Game 分基本／進階設定，預覽及開始按鈕固定。
- 設定變更使舊預覽失效；產生中、錯誤與重試提供狀態回饋。
- 交接時移除地圖與單位 DOM；暫停時禁止推進階段。

## 驗證結果

`npm.cmd run check` 通過：typecheck、34 個測試檔／168 項測試、build、smoke。

`node scripts/desktop-deck-gate.mjs` 最終執行成功，透過隔離 Edge 的實際滑鼠／鍵盤輸入操作，未直接注入 controller 行動。

| 測試尺寸 | 左欄高度 | 清單高度 | 整體左欄捲動 |
| --- | ---: | ---: | --- |
| 1920×1080 | 1016px | 350px | 無 |
| 1680×1050 | 986px | 320px | 無 |

兩種尺寸均完成 New Game 開關、預覽、設定修改使 Start 停用、重建預覽、開始遊戲、一次單位移動、五次交接及進入第 2 回合（revision 30）。另驗證暫停／恢復、checkpoint 建立與回復 revision。交接畫面無 counter、unit row 或地圖 DOM；未捕捉到瀏覽器例外或 console.error。

1680×1050 使用 Large 設定，預覽為 18×12 地圖、90 個單位、8 個 formations。畫面截圖確認清單捲動不影響固定操作區。

原始量測與截圖位於 `tmp/desktop-deck-gate/evidence.json` 及同目錄的 `default-*`、`large-*` PNG；這些是本機測試產物，不是版本化驗收附件。重跑需先建置、啟動 port 4173 的 UI server 與 port 9223 的隔離 Edge。
