# Desktop Command Deck — 版面稿與操作契約

日期：2026-09-06。狀態：DESIGN DRAFT / PRODUCT VERIFICATION UNVERIFIED。

本文件是重新設計的下一份可審閱交付，不是產品完成報告。依使用者指示，unit counter 視為已完成前置成果，沿用目前共用 renderer、projection 與 LOD；本工作不重開棋子設計。既有 counter 報告仍有歷史未結項，本文件不覆寫其證據或推定其他 gate 通過。

## 1. 已確認範圍與設計假設

- 預設寬度 1920px；接受 1680px；移除窄螢幕需求。
- 一個左側 Command Deck，無右欄；地圖占剩餘空間。
- 整頁與整個左欄不垂直捲動。Unit、HQ/Formation、Candidate、History、Checkpoint 等集合可局部捲動。
- 一個模式最多一個主要捲動清單，不允許清單內再嵌套捲動清單。
- 1920×1080、1680×1050 是使用者確認的測試畫布；380px 左欄寬度以真實內容驗證。
- 本稿中文為設計註解；產品目前英文介面不在這一步變更語系。
- 沿用現有原生 TypeScript、SVG 與遊戲公開介面。

Frontend thinking gate：既有戰棋工作台；核心旅程為設定、預覽同一作戰包、開始、合法行動、決策與交接、完成回合；資訊順序為階段與玩家、選取對象、合法行動、成本與結果。復原入口包含取消未提交選擇、重試、交接、暫停與存檔。主要風險為固定高度裁切、焦點遺失、候選過量、私密內容殘留。桌面以外不列設計目標。

## 2. 兩個畫布與高度預算

全寬頂部狀態列高 64px；其下為左欄與地圖。狀態列顯示作戰名稱、回合、階段、玩家、Session 選單；revision 位於次要詳情。

| 畫布 | 左欄 | 地圖區 | 下方工作區高度 |
|---|---:|---:|---:|
| 1920×1080 | 380 | 1540 | 1016 |
| 1680×1050 | 380 | 1300 | 986 |

左欄以 border-box 預算分配；間距與分隔線計入每列高度，非額外累加。

| 區域 | 高度預算 | 放置內容 |
|---|---:|---|
| 階段／任務 | 72 | 必須處理事項、階段返回入口 |
| 選取摘要 | 160 | 128px 完整棋子、單位名稱、Hex、必要狀態 |
| 行動控制 | 88 | 常用行動、其他行動入口、清單視圖切換 |
| 清單 | 其餘空間 | 1080 高時 480；1050 高時 450（設計預算） |
| 成本／影響 | 96 | 本次動作成本、結果或阻擋原因 |
| 執行列 | 120 | 兩行結果訊息、主要與取消按鈕、階段控制 |

這是空間配置假設，不能作為「文字一定放得下」的證據。完整棋子可放大檢視，沿用現有 full-detail 呈現。未選取時釋放選取摘要區給任務清單。超長名稱保留穩定身份標示並提供完整名稱入口；影響決策的文字不得用省略號隱藏。

```text
┌──────────────────────────────────────────────────────────────────┐
│ Operation    Turn 1 · Movement          Allied       Session ▾    │
├─────────────────────┬────────────────────────────────────────────┤
│ Phase / required    │                                            │
├─────────────────────┤                                            │
│ [full counter]      │                                            │
│ Selected unit · Hex │                  MAP                       │
├─────────────────────┤                                            │
│ Move  Mode  More    │     selection / path / legal destinations   │
│ Units | Candidates  │                                            │
├─────────────────────┤                                            │
│ bounded list      ↕ │                                            │
├─────────────────────┤                                            │
│ Cost / consequence  │                                            │
│ Result              │                                            │
│ Cancel · Execute    │                       Legend · Zoom        │
│ End phase           │                                            │
└─────────────────────┴────────────────────────────────────────────┘
```

## 3. 壓力狀態版面稿

以下示意為介面結構，不宣稱範例成本、候選數量或規則在某個現成局面成立。實際值全部由 Gameplay 公開查詢提供。

### S0 — 尚未選取

```text
階段：移動                 當前玩家
必要事項：[依遊戲查詢]
──────────────────────────────────
任務 | Units | HQ / Formations
[搜尋與篩選]
┌────────────────────────────────┐
│ 單位清單：棋子縮圖、名稱、Hex ↕ │
│ 點選列 → 地圖定位並更新摘要      │
└────────────────────────────────┘
選擇本方單位以查看可用行動
[結束階段]
```

地圖與清單均可作為單位入口。HQ/Formation 檢視只使用實際存在的關聯；不從名称推測指揮關係。敵方清單與計數遵循當前 projection。

### S1 — 多枚 Stack 與長名稱

```text
階段與玩家
[完整棋子 128×128]  單位身份
                    Hex / mode
[移動] [模式] [其他]
Stack (count) | Units
┌────────────────────────────────┐
│ 同 Hex 各單位；目前選取有標記 ↕ │
│ 選擇另一列就地換單位            │
└────────────────────────────────┘
必要狀態 / 可用行動說明
[結束階段]
```

不另開 Stack 頁再進入 Unit 頁。點擊棋子直接選到該單位；點 Hex 則顯示 Stack 並保留清楚的選取狀態。縮放、hover、選取框不得覆蓋印刷欄位。

### S2 — 地圖移動（2026-09-30 使用者決定：不使用目的地清單）

```text
階段與玩家
[完整棋子]  選取單位 / 起點
[移動 selected] [模式] [其他]
Units | Stack | …（不切到 Choices；Choices 只顯示操作提示）
地圖：完整合法範圍反白，範圍外 Hex 變暗；已選目的地與路徑另行標示
起點 → 終點；路徑成本；執行後餘額
[取消選擇] [Confirm · <Hex>]（未選目的地前停用並顯示 Choose destination）
[結束階段：若合法]
```

選取可移動的己方單位且玩家未指定其他行動時，直接進入移動。地圖顯示規則查詢回傳的**完整**合法範圍，
不設數量上限、不提供目的地清單，也不自動選取任何目的地。點反白 Hex（或站在其上的棋子）選定目的地並顯示
路徑與成本；點非合法 Hex 保留目前單位並提示原因。點選不立即提交。執行後保留單位與鏡頭，選取 Hex 移至新位置，
依新 revision 重新查詢剩餘範圍。取消只清除 UI 草稿；若已有引擎交易，必須使用合法的取消交易操作。

此決定取代先前「合法目的地清單」設計。其他候選型行動（戰鬥、砲擊、補給等）的清單設計不在此次變更範圍。

### S3 — 複合行動：參與者／目標／支付

```text
階段與玩家
行動摘要：發起方、目標、選取數
[參與者] [目標] [支付（若需要）]
┌────────────────────────────────┐
│ 當前選擇清單                 ↕ │
│ 已選值切換步驟後保留            │
└────────────────────────────────┘
參與者摘要 · 預計成本 · 未滿足條件
[取消] [Declare <action>]
```

只在規則確實需要多項選擇時使用步驟。供給支付、撤退、損失分配等引擎 pending decision 不得被假想的前置表單取代。成本或後果在 96px 中不足以清楚呈現時，進入完整的行動審閱對話框並在該處提交；不得裁切或默默擴大左欄捲動區。對話框非清單內容以分步呈現，每一步保持主操作可見。

### S4 — 載入、失敗、空清單

- 查詢中：清單區顯示進度，固定狀態列說明正在準備合法行動；禁止提交舊候選。
- 查詢失敗：保留選取與鏡頭，顯示原因、影響及重試；不得顯示成「沒有合法行動」。
- 真正空候選：說明此單位／階段的限制，提供換單位、換行動或合法交接入口。
- 執行中：鎖定重複提交並顯示 busy；不能把尚未接受的動作顯示為成功。
- 過期候選：保留選取意圖、刷新可用項，要求重新確認，不自動提交改變後的選項。
- 長錯誤：保留可行動結論及復原按鈕；完整技術原因可另外開啟。

### S5 — 決策與交接

```text
┌───────────────── 全画面隱私邊界 ──────────────────┐
│ Pass to <required player>                        │
│ [I am <required player>]                         │
└──────────────────────────────────────────────────┘
```

交接期間移除地圖、清單、tooltip、對話框與 accessible name 中的上一玩家私密內容；不能只靠遮罩。確認後依新玩家投影重建，不帶入上一玩家的私密搜尋、選取或草稿。Pending decision 依規則顯示選項、後果與擁有者，焦點限制於對話框；有合法取消選項才提供取消。

## 4. New Game 組合預覽

作為覆蓋遊戲的工作畫面，左右各留 24px，頂底各留 24px。設定欄 360px，主區使用剩餘寬度；無第三欄。

```text
┌────────────────────────────────────────────────────────────────┐
│ New Game · Configure / Review / Start                    Close │
├────────────────┬───────────────────────────────────────────────┤
│ Basic|Advanced │ 地圖預覽                  狀態 / 驗證清單       │
│                │                                               │
│ Style          ├───────────────────────────────────────────────┤
│ Width · Height │ Units · Formations · Deployment · Warnings     │
│ Scale          ├───────────────────────────────────────────────┤
│ Formations     │ Allied 摘要                 Axis 摘要           │
│ Turn limit     │ Allied | Axis · Formation filter               │
│                │ 共用棋子 renderer 的 unit 清單               ↕ │
├────────────────┴───────────────────────────────────────────────┤
│ Preview current / stale                  Build preview · Start │
└────────────────────────────────────────────────────────────────┘
```

在 1680×1050，對話框 1632×1002；預留標頭 64、底部 72，中段 866。主區預算：地圖 363、指標 56、雙方摘要與篩選 96、unit 清單 351。以上含邊框及內距，仍須驗證真實文字。1920×1080 增加的高度分配給地圖與清單。

Basic 保留必要選項，Width/Height 同列。Advanced 顯示四種 seed 與 Randomize。切換兩者不得重設輸入。預覽失效立即禁用 Start，仍可檢查帶有 stale 標示的舊預覽。生成中 Map/OOB/Deployment 狀態必須真實；不能以定時動畫假裝逐階段進度。預覽與啟動包必須保有現有整合契約。

Warnings 摘要持续可見；完整警告可作為主區清單的另一檢視，阻擋開局的原因直接出現在固定操作區。不能用一個警告數字取代阻擋原因。

## 5. 鍵盤、狀態與低頻操作

- Tab 在主要區域移動；地圖採單一焦點入口與方向鍵導航，Enter 選取，提供可見的清單替代入口。
- 清單採符合元件語義的鍵盤導航，不把所有 Hex 加入 Tab 序列。
- DOM 更新後恢復相同控件或合理後繼焦點；隱藏頁籤不能保留可聚焦元素。
- History、Checkpoint 等低頻集合替換左欄清單或使用有邊界的對話框；關閉後回到原任務與位置。
- Save/Load/Pause 由 Session 選單可達；保留現有合法生命週期限制與復原流程。
- 視覺延續深綠工作面、克制的金色主操作；選取、警告、陣營與成功各有不同語義，不能只用顏色區分。
- 不以縮小一般文字低於 13px 解決空間不足；棋子圖稿沿用已有 LOD 與 full-detail 規範。
