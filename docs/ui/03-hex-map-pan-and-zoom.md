# U3 — Hex map, pan, and zoom

## Study result

Map geometry is deterministic pointy-top axial. `buildGeneratedMapPreview` lays out the active `GeneratedMap`; the renderer does not substitute a fixed Scenario map or independent laboratory output.

Terrain is communicated graphically with color plus texture. Rivers occupy shared Hexsides; roads connect Hex centers; settlements, strategic entry/supply regions, objectives, and counters are distinct marks. Terrain names must not be printed in every Hex. The terrain name is announced for the keyboard cursor and shown in the hover line, and coordinates appear at low visual priority (darker on hover/selection).

Since 2026-10-02 the theater map is one canvas (`src/ui/map-canvas.ts`). The printed terrain is painted once per zoom level into cached tiles and panning only copies tiles; highlights, targets, the move path and counters are drawn over them from the snapshot. The artwork still comes from `src/ui/map-art.ts` and `src/ui/counter.ts` (pattern tiles and counters are rasterized from their SVG), so the canvas map and the SVG New Game preview draw the same map. Clicks resolve to hexes by axial arithmetic and to counters by their drawn rectangles.

The map supports pointer drag, wheel zoom, explicit zoom in/out, and reset. The readout is relative to a reference framing (internal render scale 1.848, `ZOOM_REFERENCE` in `src/ui/map-canvas.ts`). The default view, the Reset button, and a newly started game read 100% (`DEFAULT_ZOOM_PERCENT`). User decision 2026-10-04: the default view keeps the on-screen size it had when it read 110% (scale 1.68 × 1.1, chosen in #34 so counter text shows) and is relabelled 100%; the former 100% now reads about 91%. Each wheel notch and each +/− press moves the readout by 10 percentage points, snapping to multiples of 10. Zoom is bounded from 20% to 150% of the reference framing: the range favours zooming out; about 54% fits a 32×24 map and about 27% a 64×48 one. The framing is a fixed 32×24-hex area (the default New Game map), not the map on show, so a zoom readout gives the same on-screen hex size whatever the map's width and height (since 2026-10-04; before, the whole map was fitted into the canvas and a larger map was drawn smaller at the same readout). The window size still scales the framing. Camera position and selection are interaction state only and never enter Gameplay saves or Rule state.
