# M6.9 — Seed sweep protocol

The blocking matrix runs 500 inland and 500 coastal seeds at 18×12. Every output must pass Foundation and generator validation; exceptions, invalid maps, disconnected road networks, missing rivers, absent strategic corridors, and severe-terrain excess are failures.

The report records minimum land ratio, maximum severe-terrain ratio, and road-edge range so algorithm changes cannot silently collapse variety or connectivity. A fixed first seed makes the sweep reproducible.
