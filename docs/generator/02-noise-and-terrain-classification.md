# M6.2 — Noise and terrain classification

Four-octave value noise produces elevation, moisture, roughness, and temperature fields. Classification maps them to open, woods, rough, mountain, marsh, or water Definition IDs. It is data generation only; movement cost remains Rule Engine ownership.

A two-Hex central operational belt suppresses impassable terrain without flattening the rest of the map. Validation caps mountain plus marsh at 40% of land. Inland style does not create a sea.
