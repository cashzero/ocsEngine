# M7.2 Generator archetypes

Three mirrored formation archetypes provide variety without hidden force asymmetry:

| Archetype | Core | Additional element | Operational character |
|---|---|---|---|
| Armored | armored combat units | reconnaissance | high combat and movement |
| Infantry | one XX division unit (single-unit formation; US motorized, German leg) | none | lower movement, efficient strength |
| Mobile infantry (Axis) | mobile combat units | reconnaissance | intermediate strength and movement |
| Airborne (Allied) | one XX division (single-unit, leg; sum of its printed regiments) | none | e.g. 101.Abn 18-4-3 / 10-4-5, 4 steps; 82.Abn 14-4-3 / 8-4-5, 3 steps |
| Airborne (Axis) | one XX Fallschirmjäger division (single-unit formation, leg) | none | 18-3-3 / 9-3-4, 4 steps |

Every multi-unit archetype also receives one command element and at least one artillery element. The same seeded plan is instantiated for Allied and Axis source templates, so randomized composition remains point-balanced. The plan lists `armoredDivisionsPerSide` armored slots first (Allied armored divisions; Axis Panzer divisions with every second slot a Panzergrenadier package), then the foot slots, drawn from a seeded cycle of three infantry to one airborne so a larger force stays mostly line infantry. Independent artillery, trucks and supply dumps scale with the total division count.
